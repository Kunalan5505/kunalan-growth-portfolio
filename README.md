# Kunalan Mahendran — Performance & Growth Marketing

A responsive, case-study-led portfolio for digital marketing applications. Built with semantic HTML, CSS and vanilla JavaScript; no build step or package dependencies.

## Publish on GitHub Pages

In repository Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`.

## Local preview

Run `node preview.cjs`, then visit http://127.0.0.1:4173.

## Accessibility

Content is readable without JavaScript. Native details elements hold the case studies; hash links open them when scripting is available. Evidence links work directly without scripting and enhance to a native modal dialog with keyboard support, focus restoration and error messages. The layout includes a skip link, visible focus styles and reduced-motion support.

## Main files

- `index.html`: professional content and case studies
- `styles.css`: responsive visual system
- `script.js`: navigation, case links and evidence dialogs
- `assets/favicon.svg`: monogram

External images and Google Fonts require network access. Fonts fall back to system faces. No tracking scripts or form backend are included.
